Creating a trip starts by asking whether that address is already taken. The read
rule for a trip looked at resource.data before checking that the document exists
at all, and on a document that does not exist that is an error - which a rule
treats as a refusal. So every first trip failed with permission-denied.

One line: resource == null passes the read, exactly as "not found" should.
